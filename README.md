# Comandos / Scripts do projeto

Compilar automaticamente ao salvar arquivos TypeScript:
```ts
npm run watch
```
Compilar uma única vez:
```ts
npm run build
```

Executar um exercício e acompanhar as alterações:

```ts
npm run dev -- exercicios/1ex.ts
```
